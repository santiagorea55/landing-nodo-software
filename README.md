# Nodo Software · Landing page

Landing page de una empresa ficticia de desarrollo de software. Proyecto académico.

## Tecnologías
HTML5, CSS propio, JavaScript, [GSAP 3](https://gsap.com/) (con ScrollTrigger) y [Bootstrap Icons](https://icons.getbootstrap.com/), cargados por CDN.

## Estructura
```
index.html
css/styles.css
js/main.js
```

## Qué incluye
Navbar, hero, servicios, tecnologías, estadísticas, proyectos, cotizador, formulario de contacto y footer.

- **Animaciones GSAP:** entrada del hero, aparición de servicios, contadores de estadísticas y tarjetas de proyectos (las dos últimas con ScrollTrigger).
- **Interacción con JavaScript:** el cotizador multiplica páginas × precio y escribe el resultado en el elemento con `id="resultado"`.
